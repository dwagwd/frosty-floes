# frosty-floes

Legacy redirect-only site for the Frosty Floes brand. The canonical public website now lives in `frosty-floes-site`.

## Files

- `index.html`: redirect to the canonical Frosty Floes home page
- `support.html`: redirect to the canonical Frosty Floes support hub
- `privacy-policy.html`: redirect to the canonical Frosty Floes privacy hub
- `app-ads.txt`: ads.txt file for AdMob verification
- `assets/`: shared icon, CSS, and token files copied from the workspace `brand-system/` source

## Public URLs

- Support URL: legacy redirect to `https://frosty-floes-site.pages.dev/support.html`
- Privacy Policy URL: legacy redirect to `https://frosty-floes-site.pages.dev/privacy-policy.html`
- Landing page: legacy redirect to `https://frosty-floes-site.pages.dev/`
